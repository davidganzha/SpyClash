# SpyClash: устранение дефектов HTTP 409 — Build 157

## Результат

Исправления подготовлены и проверены локально; после отдельного подтверждения пользователя шесть функций production обновлены 15 сентября 2026. [Подтверждение применения и обратная проверка](deployment-2026-09-15.md). Сайт, TestFlight и App Store не изменялись. Гарантировать отсутствие любых будущих 409 невозможно: конфликт состояния остаётся частью защиты многопользовательской игры и удаления аккаунта.

Рабочая ветка: `davidganzha/409-system-hardening`, база `cf82a56b9a4e78606c30004e165c30e5bb582fce` (пакет Build 156). Версия iOS повышена до `1.0.1 (157)` в обоих файлах проекта. Исходная папка `Documents/SpyClash` возвращена к её начальному состоянию Build 148 после переноса исследовательских исправлений; её существующие неотслеживаемые файлы сохранены.

## Найденные и исправленные дефекты

| Область | Дефект | Результат |
|---|---|---|
| Версия комнаты | `null`, строки и boolean превращались в числовой 0; сравнение при записи никогда не совпадало | Некорректные версии проходят восстановление под блокировками участников |
| Игровые переходы | Подтверждение карточки/голос мог сорвать переход; повтор мог пересечь новый матч, паузу или таймер | Ограниченный повтор одного неизменного перехода с повторной проверкой фазы, игрока, матча и срока |
| QR / возврат в комнату | Разные бюджеты повторов, сопоставление по английскому тексту, риск ответа после смены аккаунта | Единый ограниченный повтор по явному коду; сохранены membership ID и поколение аккаунта |
| Уведомления | Отдельный старый протокол блокировок не имел общей защиты от потерянного CAS-ответа и гонки удаления дублей | Общий протокол точного владельца блокировки; успешная запись сохраняет успех при ошибке очистки |
| Community / Push / WordPack | Поздняя ошибка могла разрешить повтор уже частично выполненного действия; удаление аккаунта помечалось повторяемым | Запрет повтора после входа в действие; удаление не вызывает цикл повторов |
| AI | Запрет повтора мог быть снова превращён в разрешение; live-handler не отмечал начавшиеся побочные эффекты | Сохраняется явный запрет; ошибки после квоты/провайдера не вызывают автоматический повтор |
| Live Activity / device push | Любой 409 мог запускать новые отложенные попытки; задержка сервера терялась | Повтор только разрешённых временных конфликтов, с учётом `Retry-After` |
| Приглашения | Любой 409 считался завершённой очисткой приглашения | Временный конфликт оставляет очистку в очереди; iOS распознаёт отдельный постоянный код |
| Web transport | Axios-код заслонял код сервера; явный запрет повтора терялся | Приоритет серверного кода и `retryable:false` |
| Web lobby | Повтор полного старого снимка мог затереть изменения другого устройства; подтверждённая устаревшая операция повторялась бесконечно | Сверка исходных настроек, ограничение повторов и откат к актуальному состоянию |
| Web AI | Запрос генерации не имел стабильного идентификатора | Один `request_id` на пользовательское действие; нет автоматического повтора неизвестного результата |

Правомерные 409 сохранены: действующее удаление аккаунта, неподтверждённая смена личности, занятая/закрытая комната, конфликт настроек, другой матч, пауза/истёкший таймер, конкурирующий защищённый writer. Уничтоженный процесс может удерживать допустимую блокировку до её срока; принудительно снимать чужую активную блокировку небезопасно.
